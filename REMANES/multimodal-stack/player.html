🏗️ Arquitetura Multimodal

Sistema multi-agente orquestrado por CrewAI, combinando detecção com YOLOv8, rastreamento com DeepSORT, transcrição com Whisper e análise semântica via LLM Multimodal. Consulte o arquivo completo em 📄 ARCHITECTURE.md .

🤖 Agentes

# Agente Ferramenta
1Vision AgentYOLOv8
2Tracking AgentDeepSORT / ByteTrack
3Audio AgentWhisper
4Context AgentLLM Multimodal
5Optimization AgentEnsemble + Heurísticas
6Visualization AgentOpenCV + Matplotlib

🔄 Pipeline

INPUT (vídeo / stream / voz) └─▶ Pré-processamento ├─▶ Detecção YOLOv8 ──▶ Tracking (DeepSORT) └─▶ Análise de Áudio (Whisper) │ │ └──────────┬────────────┘ ▼ Análise Semântica (LLM) │ Otimização (Ensemble) │ SAÍDA (overlay · JSON · heatmap · PDF)

📊 Saída JSON por Frame

  • frame — número do frame
  • timestamp_ms — posição em milissegundos
  • objects[] — lista de objetos detectados (bbox, id, confiança, velocidade)
  • scene — contexto semântico da cena
  • audio — transcrição e eventos sonoros
  • anomalies[] — anomalias detectadas
  • heatmap_zone — zona de maior movimentação

⚙️ Dependências Principais

  • crewai ≥ 0.28.0
  • ultralytics ≥ 8.0.0 (YOLOv8)
  • opencv-python ≥ 4.9.0
  • openai-whisper ≥ 20231117
  • deep-sort-realtime ≥ 1.3
  • torch ≥ 2.1.0
